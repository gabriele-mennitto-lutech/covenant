AVVIO COVENANT - SOC INFRA (WINDOWS / POWERSHELL)

Aprire tre terminali nella directory principale del repository.
Configurare il PATH in ciascun terminale prima di usare npm.
Eseguire npm.cmd ci --include=dev al primo avvio e dopo modifiche al lockfile.
Le directory assolute funzionano anche se il terminale e' gia' in un servizio.

TERMINALE 1 - DATASERVICE
$env:PATH = "C:\Users\elut235\Documents\VSCode\Unix CMDB\bin\node;" + $env:PATH
Set-Location "C:\Users\elut235\Documents\VSCode\Infra CMDB\dataservice"
npm.cmd ci --include=dev
npm.cmd run dev

TERMINALE 2 - BACKEND
$env:PATH = "C:\Users\elut235\Documents\VSCode\Unix CMDB\bin\node;" + $env:PATH
Set-Location "C:\Users\elut235\Documents\VSCode\Infra CMDB\back-end"
npm.cmd ci --include=dev
npm.cmd run dev

TERMINALE 3 - FRONTEND ANGULAR
$env:PATH = "C:\Users\elut235\Documents\VSCode\Unix CMDB\bin\node;" + $env:PATH
Set-Location "C:\Users\elut235\Documents\VSCode\Infra CMDB\angular-app"
npm.cmd ci --include=dev
npm.cmd start

URL:
- frontend: http://localhost:4200/
- backend Swagger: http://localhost:9991/api-docs/
- dataservice Swagger: http://localhost:9992/docs/
- Compodoc: http://localhost:9991/fe-docs/

Il proxy Angular inoltra automaticamente `/api` al backend. Se il progetto
viene eseguito in un ambiente in cui Node non è nel PATH, aggiungere al PATH
il binario Node fornito dal setup locale prima di eseguire npm.

BUILD PRODUCTION

cd dataservice
npm run build
npm start

cd back-end
npm run build
npm start

cd angular-app
npm run build

Pubblicare angular-app/dist/angular-app/browser con IIS, configurando il
fallback SPA e il reverse proxy /api verso il backend. Vedere il README.
Usare un DB_PATH dedicato a Covenant, senza condividere il database originale.
